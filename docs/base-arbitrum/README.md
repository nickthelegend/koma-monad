# Pre-existing base (KOMA on Arbitrum)

KOMA was first built for Arbitrum before the Monad Metropolis window. These documents describe that earlier
build — its plan, test results, mainnet runbook and launch copy — and are kept unchanged for provenance. They are
**not** about the Monad version. For the Monad version see the top-level `README.md`, `SUBMISSION.md`,
`docs/SPONSOR-GAP.md` and `docs/DEPLOY-LATER.md`.
